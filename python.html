Python Programming

Created by Guido van Rossum in 1991, Python is an interpreted, high-level programming language famous for its English-like syntax. Instead of curly braces or semicolons, Python uses indentation (spaces) to organize code blocks.

Key Terms & Symbols

Symbol / Term Meaning & Usage
# Comment: Everything after # on that line is ignored by Python and used for human notes.
= Assignment Operator: Stores a value inside a variable (e.g., age = 20).
: and Indentation Code Block: A colon starts a block (like an if statement or loop), and 4 spaces indent the lines inside it.
def Function Definition: Keyword used to create a reusable block of code.
Interpreter A program that reads and executes Python code line by line without needing a separate compile step.

Lessons: Writing Python Code

Lesson 1: Output & Variables

Use the print() function to display text on the screen, and store data in variables without declaring their type.

# Storing information in variables
language = "Python"
version = 3

# Displaying output using an f-string
print(f"Welcome to {language} {version}!")

Lesson 2: Decisions & Loops

Use if/else to make decisions and for loops to repeat actions.

score = 85

if score >= 50:
    print("You passed!")
else:
    print("Try again.")

# Loop from 1 to 3
for number in range(1, 4):
    print("Count:", number)
