C Programming

Developed by Dennis Ritchie in 1972 at Bell Labs, C is a compiled, procedural language that sits close to computer hardware. Operating systems like Linux and Windows, as well as embedded microcontrollers, rely heavily on C.

Key Terms & Symbols

Symbol / Term Meaning & Usage
; Semicolon: Marks the end of every statement in C. Forgetting it causes a compiler error.
{ } Curly Braces: Group statements together into functions, loops, or conditionals.
#include Preprocessor Directive: Imports external header libraries (like <stdio.h> for input/output) before compiling.
* and & Pointers & Addresses: & gets a variable's memory address; * accesses the value stored at a memory address.
Compiler A tool (like GCC) that translates your entire C code into machine-readable binary before it runs.

Lessons: Writing C Code

Lesson 1: Program Structure & Data Types

Every C program starts running inside the main() function, and every variable must have an explicit data type like int (integer) or float (decimal).

#include <stdio.h>

int main() {
    int year = 1972;
    printf("C was created in %d.\n", year);
    return 0; // Signals the program ended successfully
}

Lesson 2: User Input & Loops

Use scanf() with the & symbol to read input into a variable's memory location.

#include <stdio.h>

int main() {
    int i;
    for (i = 1; i <= 5; i++) {
        printf("Step %d\n", i);
    }
    return 0;
}
