Block-Based Coding Basics

Before learning to type text commands with semicolons and brackets, block-based coding (used in platforms like Scratch and Blockly) teaches the core logic of programming using interlocking visual blocks. Because blocks only snap together when they make logical sense, you never have to worry about syntax errors.

Core Concepts in Block Coding

Concept Block Category What It Does
Events Amber Hat Blocks Triggers when a script starts (e.g., when the Green Flag is clicked or a key is pressed).
Sequence Stacked Blocks Runs instructions strictly from top to bottom, one step at a time.
Loops Orange C-Blocks Repeats the blocks placed inside its jaws a set number of times or forever.
Conditionals Orange If/Else Blocks Checks whether a condition is true or false before deciding which blocks to run.
Variables Pink Value Blocks Stores changing numbers or text like score or playerName.

Lessons: Reading & Snapping Blocks

Lesson 1: Events & Sequences

Every block program begins with an Event block at the top. The computer executes each connected block below it in exact order:

when ▶ Start clicked
say Hello! Ready to code? for 2 secs
move 10 steps

Lesson 2: Loops & Conditionals

Instead of stacking the same block over and over, wrap it inside a repeat loop and check a condition with if / then:

when ▶ Start clicked
set score to 0
repeat 3 times
change score by 10
if score = 30 then
say You Win!
