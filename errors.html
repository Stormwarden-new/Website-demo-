Programming Errors & Debugging

Even experienced programmers encounter mistakes when writing software. Understanding the three main categories of programming errors—and how to systematically remove them—is an essential skill in every coding language.

Types of Programming Errors

Error Type Definition When It Happens
Syntax Error An error in how the statements in source code are written in a particular program. Before the program runs (caught by the compiler or interpreter).
Logic Error A mistake in the design of the program. While the program runs (the program finishes without crashing, but produces the wrong result).
Run-Time Error A program error that occurs during program execution. While the program is actively running (often causing it to freeze or crash).

Detailed Breakdown & Examples

1. Syntax Error

Definition: An error in how the statements in source code are written in a particular program. Just like grammar rules in human languages, every coding language has strict punctuation and keyword rules.

Example: Forgetting to place a semicolon (;) at the end of a statement in C or C++.

// Incorrect C++ code (missing semicolon on line 4)
#include <iostream>

int main() {
    std::cout << "Hello World"   // Syntax Error: expected ';' before 'return'
    return 0;
}

2. Logic Error

Definition: A mistake in the design of the program. The code follows all syntax rules and runs from start to finish without crashing, but flawed reasoning causes it to behave incorrectly.

Example: Using the wrong comparison operator so that a system treats 100% safety as a hazard while marking 40% safety as secure.

# Incorrect Python logic (using < instead of >=)
safety_level = 100

if safety_level < 50:
    print("Status: Secure")   # 40% triggers this!
else:
    print("Status: Hazard")   # 100% triggers this!

3. Run-Time Error

Definition: A program error that occurs during program execution. The syntax is valid, so the program starts running normally, but it encounters an impossible operation while executing.

Example: Attempting to divide a number by zero (or asking the user for a number and receiving text instead).

# Valid syntax, but crashes during execution
total_points = 100
players = 0

average = total_points / players  # Run-Time Error: ZeroDivisionError

What is Debugging?

Debugging is the process of finding and removing errors from computer hardware and software.

Common debugging techniques include:

  • Reading Error Messages: Compilers and interpreters usually report the exact line number where a syntax or run-time error occurred.
  • Print Tracing: Temporarily printing variable values at different points in the program to spot where a logic error changes a value unexpectedly.
  • Step-by-Step Execution: Using a debugger tool to pause code line by line and inspect memory and variables in real time.
