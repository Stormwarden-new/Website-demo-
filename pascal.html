Pascal Programming

Designed by Niklaus Wirth in 1970 and named after mathematician Blaise Pascal, Pascal was built to encourage structured programming and strict data typing. It remains widely used in computer science education and legacy desktop software (via Delphi/Free Pascal).

Key Terms & Symbols

Symbol / Term Meaning & Usage
:= Assignment Operator: Assigns a value to a variable (distinct from =, which checks equality).
begin ... end Block Keywords: Used instead of curly braces to mark the start and end of code blocks.
end. Program Terminator: The final end of a Pascal program always ends with a period (.).
var Variable Declaration: Section at the top of a program where every variable and its type must be declared beforehand.
{ } or (* *) Comments: Text enclosed inside curly braces is ignored by the Pascal compiler.

Lessons: Writing Pascal Code

Lesson 1: Structure & Variables

Notice how variables are declared under var before begin, and values are assigned using :=.

program Greeting;
var
  userName: string;
  age: integer;
begin
  userName := 'Alex';
  age := 18;
  writeln('Hello, ', userName, '! You are ', age, ' years old.');
end.

Lesson 2: Conditionals & For Loops

Pascal reads almost like structured English using if ... then ... else and for ... to ... do.

program Counting;
var
  i: integer;
begin
  for i := 1 to 5 do
  begin
    if i mod 2 = 0 then
      writeln(i, ' is even')
    else
      writeln(i, ' is odd');
  end;
end.
