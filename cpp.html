C++ Programming

Created by Bjarne Stroustrup in 1985 as "C with Classes," C++ builds directly on C while adding Object-Oriented Programming (OOP) and modern standard libraries. It powers AAA video games, 3D engines, and high-frequency trading systems.

Key Terms & Symbols

Symbol / Term Meaning & Usage
:: Scope Resolution Operator: Accesses items inside a namespace or class (e.g., std::cout).
<< and >> Stream Operators: << sends output to the screen (cout); >> reads keyboard input (cin).
// Single-Line Comment: Ignores everything after // on that line.
class Blueprint: Defines a custom data type bundling variables (attributes) and functions (methods) together.
Namespace A container (like std) that prevents naming conflicts in large projects.

Lessons: Writing C++ Code

Lesson 1: Input and Output Streams

C++ uses the <iostream> library and std::cout for clean text output.

#include <iostream>
#include <string>

int main() {
    std::string topic = "C++";
    std::cout << "Mastering " << topic << "!" << std::endl;
    return 0;
}

Lesson 2: Classes & Objects

A class lets you model real-world objects in your code.

#include <iostream>

class Player {
public:
    int health = 100;
    void takeDamage(int amount) {
        health -= amount;
    }
};

int main() {
    Player hero;
    hero.takeDamage(25);
    std::cout << "Remaining health: " << hero.health << "\n";
    return 0;
}
